# Card Types

*Status: draft. Decision to confirm: type per half vs. type per card.*

Every entity deck card has a **type** and may have **traits**. Types are shared across all scenarios, so character cards can be written once ("cancel an Attack") and work everywhere.

## Types

| Type | What it does |
|---|---|
| **Attack** | Deals damage to players. |
| **Hazard** | Disrupts cards: discard, exhaust, or other disruption. |
| **Summon** | Creates minions or other board cards. |
| **Curse** | Manipulates the economy: omen, gold, Dread. |
| **Story** | Advances or changes the story. Can't be cancelled or prevented (placeholder). |

## Traits

Traits are extra tags printed on entity cards and board cards. They are scenario-specific (for example **Tentacle**, **Storm**, **Deep**, **Minion**) and are used for targeted effects, such as "deal +1 damage to Tentacles".

## Rules
- **Split cards have a type per half.** A split card's current type is the type of the half indicated by the arrow of the card before it. Redirect can therefore change a card's type, not just its effect. *(Decision to confirm. The alternative is one type per card.)*
- **Single-effect cards** have one type.
- **Dread effects and board effects** aren't cards, so they have no type.
- **Board cards** use traits only. Types apply to entity deck cards.

## Example character cards (placeholders, character design is not started)
- **Ward** *(Attack)*: Prevent up to 3 damage from an Attack.
- **Lookout** *(Summon)*: When a Summon is revealed, remove 1 omen from the pool.
- **Purge** *(Curse)*: Cancel a Curse effect. Add 1 omen.
- **Harpoon** *(Tentacle trait)*: Deal 2 damage to a Tentacle. Deal 3 if it was created this round.
